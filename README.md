# n8n-learning

ריפו לימודים בלבד: n8n, Docker Desktop ב-Windows, ו-OAuth ל-Google Sheets / Gmail.

**חשבון:** `botbikamordehai2-sketch` (משתמש אישי, לא ארגון).
**סטטוס:** public.
**ממשל:** מקורות-העל נשארים ב-[github-sync](https://github.com/botbikamordehai2-sketch/github-sync). הריפו הזה לא משנה GOVERNANCE / SAFETY_RULES / STATUS.

## מבנה

| נתיב | תפקיד |
| --- | --- |
| `docs/` | סיכומי מחקר עם תיוג FACT / OBSERVATION / UNVERIFIED |
| `notes/` | פתקי לימוד קצרים |
| `oauth/` | רשימות scopes בלבד — בלי client secrets |
| `docker/` | הערות הרצה / compose לדוגמה |
| `workflows/` | ייצוא n8n (JSON) בלי credentials |

## כללים

- אין secrets, `.env`, tokens, או מפתחות.
- כתיבה ל-`main` רק אחרי אישור מוטי.
- תיוג טענות: FACT / OBSERVATION / UNVERIFIED.
- לימודים בלבד — לא אוטומציה חיה, לא מסחר.
